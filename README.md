# AUREXIS — Digital Headquarters

**Transforming the surfaces that shape experience.**

Aurexis is a premium surface transformation company founded in Harare, Zimbabwe (2022), now operating from Cape Town, South Africa. We specialise in automotive wraps, architectural films, glass solutions, commercial branding, interior graphics, and event branding.

---

## 🎯 About This Project

This repository contains the complete corporate website for Aurexis — a design-forward, Swiss-inspired digital headquarters. It was built to feel like an ambitious African company with world-class standards, not a fictional multinational.

**Design philosophy:** Minimal. Honest. Architectural. No stock-photo clichés. No exaggerated claims. Just real photography and truthful copy.

---

## 🛠️ Tech Stack

- **HTML5** — Semantic, accessible structure
- **CSS3** — Custom properties, Flexbox, Grid, animations
- **Vanilla JavaScript** — No frameworks, no dependencies
- **Google Fonts** — Inter (weights 300, 400, 500, 700)
- **Unsplash** — Real, context-accurate photography
